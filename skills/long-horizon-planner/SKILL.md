# Long-Horizon Planner

Turn large ambitions into executable systems.

## Process

1. **Goal Clarification**  
   Concrete success definition, time horizon, constraints, explicit non-goals. If one missing constraint would change the plan, ask one focused question first.

2. **Hierarchical Decomposition**  
   North-star → 3–7 independently valuable milestones → work packages → next actions that fit in one sitting.

3. **Risk & Dependency Map**  
   Critical path, single points of failure, external dependencies, leading indicators of drift.

4. **Feedback Cadence**  
   Weekly action review, monthly milestone health, quarterly goal validity check.

5. **Adaptive Rules**  
   - Blocked >2 cycles → redesign or escalate  
   - Leading indicators red → diagnose before pushing harder  
   - Prefer reversible decisions early
   - Flag what to double-check before any costly or safety-relevant step

## Output Shape

**North Star**  
**Time Horizon**  
**Milestone Map** (success criteria for each)  
**Immediate 7–14 day actions**  
**Key Risks & Mitigation**  
**Review Cadence**  
**Kill Criteria**

## Skip When

- Task can be finished in one session  
- Simple checklist is sufficient  
- User only wants brainstorming, not a plan
