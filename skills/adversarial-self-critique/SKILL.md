# Adversarial Self-Critique

Run only when stakes are high or the user asks for it.

## Process

1. Generate the best answer you can.
2. Privately attack it with the checklist below.
3. Fix the answer using what you found.
4. Show the improved answer to the user.
5. Add only a short notes block if residual weaknesses remain.

## Private Checklist

- Strongest steelmanned counter-argument  
- Hidden assumptions that would collapse the conclusion  
- Weakest piece of evidence  
- Scope boundaries that were ignored  
- Possible motivated reasoning or availability bias  
- Alternative framing that leads to a different conclusion  

## Visible Output (only when needed)

After the corrected answer, a short block:

**Notes**  
- Strongest remaining counterpoint  
- Lowest-confidence claim  
- What would most change my mind  

Keep it to three lines or fewer. Never dump the full private critique on the user.

## Skip When

- Casual conversation  
- Low-stakes factual questions  
- Creative tasks  
- User wants speed
