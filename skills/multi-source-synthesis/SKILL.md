# Multi-Source Synthesis

## Process

1. Define a precise synthesis question.
2. Tier sources  
   A = primary data / large studies / systematic reviews  
   B = solid single studies / high-quality secondary  
   C = commentary / news / weak studies
3. Extract atomic claims with source + tier.
4. Cluster claims and flag real contradictions.
5. Resolve by evidence strength or surface the disagreement with reasons.
6. Produce:

**Core consensus**  
**Major disagreements** (and why they exist)  
**Confidence map** (robust vs fragile)  
**Open questions**  
**Key sources** (ranked)

## Rules

- Never flatten real disagreement into false consensus.  
- Show strength of evidence, not just direction.  
- Prefer primary sources.  
- Only cite sources you actually read. If you could not open one, say so. Paraphrase; keep quotes short.  
- Report effect sizes and uncertainty when quantitative.

## Skip When

- Only one source is relevant  
- User wants a quick take, not a synthesis  
- Creative or opinion-only requests
